# legacy —— 项目前身（原样保留，不参与运行）

这里放的是这个项目"进化之前"的东西，只作历史留存，**不会被任何代码 import**。

## `小破站免费视频采集.py`

整条链路的起点：一个把所有东西写死在文件里的单文件脚本。

- 里面硬编码了 UA、一个固定的视频地址、固定的保存路径 `F:\用户\视频`
- 只能下一个写死的视频，不能搜索、不能指定
- **已处理**：这个文件原本硬编码过一份 Cookie（`SESSDATA` / `bili_jct`）。
  迁移时已改为从环境变量 `BILI_COOKIE` 读取，仓库里不再含任何凭据
- 音视频合并那段被注释掉了 —— 所以它实际只下视频轨，出的文件没声音

它的第一代"函数化 + 参数化"版本是 `bili_downloader.py`（后来被 `bili_core.py` 取代，
见 git 标签 `v0-重构前`）。

## 这些能力现在在哪

| 原来怎么做 | 现在怎么做 |
| --- | --- |
| 改源码里的 `GeBuLin_url` 换视频 | `python main.py --url "BV号"`（还支持分P、短链、合集） |
| 硬编码 Cookie | `run_login.bat` 弹浏览器登录一次，自动存 `bili_session.json` |
| 改 `lujing` 换保存目录 | `-p "目录"`，或网页版填路径 |
| 音视频合并（当时被注释） | `bili_core.download()` 里已实现，且音轨用 aac |
| 一个一个下 | 关键词搜索批量下 / 网址清单批量下 / 合集整包下 |
